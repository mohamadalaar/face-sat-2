# MyPlayer
مشغّل وسائط لهواتف أندرويد وأجهزة TV (Kotlin + Compose + Media3).
1. افتح المجلد في Android Studio (Koala أو أحدث) وانتظر Gradle Sync.
2. شغّل على موبايل أو محاكي Android TV.
3. الصق رابط M3U الخاص بك (محتوى تملكه أو مرخّص) واضغط "تحميل".
لتغيير الاسم: android:label في AndroidManifest + rootProject.name.
لتغيير الأيقونة: Image Asset في Android Studio.
